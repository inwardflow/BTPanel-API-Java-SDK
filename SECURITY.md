# Security Policy

## Supported Versions

The project is still pre-`1.0`, so security fixes are provided on the main development line unless noted otherwise in a release.

## Reporting a Vulnerability

Please do not disclose vulnerabilities in a public GitHub issue.

Report security concerns privately to:

- `dev@heimeng.net`

When possible, include:

- affected versions or commit range
- reproduction steps
- impact assessment
- suggested mitigations or existing workarounds

We will review the report, confirm receipt, and coordinate a fix and disclosure plan.
